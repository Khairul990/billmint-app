BillQyro Theme Icon Pack

এই ZIP-এর ভিতরে প্রতিটা theme-এর জন্য আলাদা icon set আছে।

প্রতিটা theme folder-এ আছে:
- favicon.ico
- favicon-16x16.png
- favicon-32x32.png
- icon-192x192.png
- icon-512x512.png
- apple-touch-icon.png

ব্যবহার করার সবচেয়ে সহজ উপায়:
1) যে theme active/default রাখতে চাও, সেই theme folder খুলবে।
2) ওই ৬টা file copy করে project-এর public folder-এ paste/replace করবে।

Dynamic theme favicon চাইলে Antigravity-কে বলবে:
- Login UI logo / Welcome Board logo change করবে না।
- শুধু browser favicon active theme অনুযায়ী বদলাবে।
- PWA/mobile icon browser/phone cache-এর জন্য instant change নাও হতে পারে।
