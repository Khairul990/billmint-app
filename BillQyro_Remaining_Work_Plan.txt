২. Antigravity-এর জন্য Master Rules
Brand name সব জায়গায় BillQyro থাকবে। পুরোনো BillMint নাম ব্যবহার করা যাবে না।
Existing PWA, PDF download, Live Invoice Link, publicInvoices, payment proof, dashboard, settings, admin panel—কিছু break করা যাবে না।
User dashboard সহজ রাখতে হবে; normal shop owner যেন বুঝে use করতে পারে।
Admin panel heavy করা যাবে না। Admin panel শুধু platform, users, free/premium plan, limit, feature access control করবে।
Customer public invoice page সবসময় read-only থাকবে। Customer edit করতে পারবে না; শুধু view, pay, proof submit করতে পারবে।
Existing invoice snapshots change করা যাবে না। New settings শুধু new invoice-এ apply হবে।
Default language English থাকবে। Country শুধু currency/payment/tax control করবে; language শুধু UI labels control করবে।
Production build অবশ্যই শেষে run করতে হবে এবং zero errors হতে হবে।

৪. Task 1 - Smart Country Setup + Regional Settings
লক্ষ্য: নতুন user প্রথম login-এর পর country select করবে। Country অনুযায়ী currency, payment method, tax label, invoice defaults auto set হবে।
First login setup wizard দেখাবে যদি setupCompleted false/missing থাকে।
Step 1: Country select - India, Bangladesh, Other।
Step 2: Business Profile - business name, owner name, phone, email, address, optional logo।
Step 3: Payment Setup - country অনুযায়ী fields auto change।
Step 4: Language - default English; options English, Bengali, Hindi।
India হলে INR ₹, UPI, Manual, GST, UPI ID, Payee Name, optional GSTIN।
Bangladesh হলে BDT ৳, bKash, Nagad, Rocket, Manual, VAT, wallet number fields।
Other হলে manual currency, Manual/Bank Transfer/Custom Payment Link, Tax।
Settings page-এ Regional Settings section থাকবে।
Invoice create করার সময় regionalSettingsSnapshot, businessSnapshot, paymentSettingsSnapshot save করতে হবে।
Live invoice link এবং PDF snapshot data use করবে, current changed settings নয়।
Task 1 Testing

India select করলে ₹/UPI/GST আসে, bKash/Nagad hide থাকে।

Admin dashboard summary: total users, active users, free users, premium users।
User management: block/unblock user, plan view।
Plan & Feature Control section add করতে হবে।

Feature access control: Live Invoice Link, Payment Proof, Custom Logo, Premium PDF Themes, WhatsApp Share, Cloud Sync, Reports, Customer Database।
Feature access option: Free / Premium / Disabled।

৮. Task 5 - IndexedDB Offline Storage Upgrade
লক্ষ্য: LocalStorage unlimited নয়। তাই LocalStorage-কে main database না রেখে IndexedDB ব্যবহার করতে হবে।
LocalStorage থাকবে small settings, theme, language, quick flags, draft state-এর জন্য।
IndexedDB থাকবে invoices, customers, payment history, offline drafts, sync queue-এর জন্য।
Firebase/Firestore থাকবে cloud sync, cross-device data, public live invoice links-এর জন্য।
Existing localStorage invoices first-load migration করে IndexedDB-তে copy করতে হবে।
Migration successful না হওয়া পর্যন্ত old localStorage data delete করা যাবে না।
Sync status add করতে হবে: Synced, Offline Saved, Sync Pending, Sync Failed।
Online হলে save to IndexedDB + Firestore। Offline হলে save to IndexedDB + syncPending।
Internet ফিরে এলে pending invoices Firestore/publicInvoices sync হবে।
PDF files বা large base64 screenshots LocalStorage-এ রাখা যাবে না।
IndexedDB Testing
Internet off করে invoice save করলে Offline Saved/Synced Pending দেখায়।
Internet ফিরে এলে sync হয়।
LocalStorage quota error আসে না।
Existing invoices migrate হয়।
