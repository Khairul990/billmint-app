# BillQyro Domain Launch Checklist

## Domain Details
- **Domain**: billqyro.com
- **Hosting**: Vercel (SPA with rewrites)
- **SSL**: Automatic via Let's Encrypt (Vercel)
- **PWA Scope**: billqyro.com/*
- **Firebase Auth Domains**: billqyro.com, www.billqyro.com, app.billqyro.com

---

## DNS Configuration (Registrar)

```
Record Type   | Name  | Value
------------- | ----- | ------------------------
A             | @     | 76.76.21.21 (Vercel IP)
A             | @     | 76.76.21.22 (Vercel IP)
CNAME         | www   | cname.vercel-dns.com
CNAME         | app   | cname.vercel-dns.com
```

**Optional:**
- `CNAME i @` — short link redirects (e.g., billqyro.com/i/TOKEN)
- `TXT @ v=spf1 include:_spf.google.com ~all` — if using Gmail

### DNS Propagation
- DNS changes can take 5 minutes to 48 hours
- Verify with `dig billqyro.com` or `nslookup billqyro.com`

## Vercel Setup

### 1. Add Domain in Vercel
1. Go to Vercel Dashboard > BillQyro Project > Settings > Domains
2. Add `billqyro.com`
3. Add `www.billqyro.com`
4. Vercel will provide DNS target values

### 2. Environment Variables (Production)
Set in Vercel Dashboard > Settings > Environment Variables:

```
VITE_FIREBASE_API_KEY=AIza...
VITE_FIREBASE_AUTH_DOMAIN=billqyro.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=billqyro
VITE_FIREBASE_STORAGE_BUCKET=billqyro.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=1:...
VITE_FIREBASE_MEASUREMENT_ID=G-...
VITE_ADMIN_EMAIL=khairul2052007@gmail.com
VITE_APP_CHECK_SITE_KEY=... (if App Check is enabled)
```

### 3. Deploy
```bash
vercel --prod
# or via GitHub integration (auto-deploy on push to main)
```

## Firebase Console Setup

### 1. Authorized Domains (Authentication)
Add in Firebase Console > Authentication > Settings > Authorized domains:
- `billqyro.com`
- `www.billqyro.com`
- `app.billqyro.com`

### 2. Firestore Rules
```bash
firebase deploy --only firestore:rules
```

### 3. Storage Rules
```bash
firebase deploy --only storage:rules
```

### 4. Firebase App Check (Optional but Recommended)
1. Go to Firebase Console > App Check
2. Register your web app with reCAPTCHA v3
3. Add the site key to `VITE_APP_CHECK_SITE_KEY` env var
4. Enforce App Check on Firestore and Storage

## Rollback Plan
If issues arise after domain switch:
1. Set DNS back to old Vercel deployment URL
2. Or use Vercel's instant rollback feature
3. Clear CDN cache in Vercel Dashboard
4. Hard refresh users: `localStorage.clear()` guidance in support
