# BillQyro — Smart Billing &amp; Premium Invoices

**BillQyro** is a premium, fully production-ready, mobile-first SaaS-style billing and invoicing platform. It is engineered specifically for small shops, embroidery, repair, and service-based businesses.

## ✨ Core Features
- **Responsive Navigation**: Mobile floating bottom nav and desktop-oriented fixed sidebar.
- **Client CRM Database**: Add, edit, remove, and filter customer records seamlessly.
- **Product &amp; Services Catalog**: Pre-define rates, descriptions, and catalog sizes.
- **Secure Admin Panel**: Guard business profiles, GST/Tax configuration, and database backups with a customizable passcode (Default: `1118`).
- **One-click High-Fidelity PDF Generation**: Print or download beautiful standard A4 or compact A5 invoices cleanly.
- **Dark Mode Optimization**: A visually stunning dark theme adapted across all components.

## 🚀 How to Run Locally

### 1. Install Dependencies
```powershell
npm install
```

### 2. Start Local Development Server
```powershell
npm run dev
```

### 3. Compile Production Bundle
```powershell
npm run build
```
